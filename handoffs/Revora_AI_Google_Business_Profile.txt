5. EXACT API CONTRACT (MIMICS GOOGLE BUSINESS PROFILE API v4 + CLOUD PUB/SUB)
--------------------------------------------------------------------------------
All API routes MUST include CORS headers allowing `http://localhost:3000` and
`http://localhost:4000` (plus `OPTIONS` preflight returning `204`):
  Access-Control-Allow-Origin: *
  Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS
  Access-Control-Allow-Headers: Content-Type, Authorization, X-Sandbox-Webhook-Secret

Persistence:
  Store reviews in a local JSON file: `apps/mock-google/data/reviews.json`
  Seed at least 15 realistic fictional reviews across all 3 locations
  (`loc-blr-001`, `loc-goa-002`, `loc-jpr-003`) covering all 6 hackathon
  scenarios: praise, suggestions, cleanliness, billing, safety, and mixed.

Authentication Rule on `/api/v4/**`:
  Check `Authorization` header === `Bearer sandbox-gbp-token`
  (or `process.env.SANDBOX_GBP_TOKEN || "sandbox-gbp-token"`).
  If missing or invalid, return HTTP `401` JSON:
    { "error": { "code": 401, "message": "Invalid or missing OAuth2 bearer token", "status": "UNAUTHENTICATED" } }

--- Endpoint 1: List Reviews (Mimics `accounts.locations.reviews.list`) ---
GET /api/v4/accounts/:accountId/locations/:locationId/reviews
  Query params:
    - pageSize (optional, default 20, max 50)
    - pageToken (optional, numeric string offset)
    - orderBy (optional: "updateTime desc" | "rating desc" | "rating asc")
  Validation:
    - Return 404 if accountId !== "acc-aurum-01" or locationId not in
      ["loc-blr-001", "loc-goa-002", "loc-jpr-003"].
  Response `200 OK`:
  {
    "reviews": [
      {
        "reviewId": "gbp_rev_101",
        "locationId": "loc-blr-001",
        "reviewer": {
          "profilePhotoUrl": "",
          "displayName": "Aarav Sharma",
          "isAnonymous": false
        },
        "starRating": "FIVE",
        "comment": "Seamless check-in and spotless rooms! The breakfast buffet at Aurum Grand Bengaluru was outstanding.",
        "createTime": "2026-11-24T09:30:00Z",
        "updateTime": "2026-11-24T09:30:00Z",
        "reviewReply": null
      }
    ],
    "averageRating": 4.2,
    "totalReviewCount": 6,
    "nextPageToken": null
  }
  NOTE: `starRating` MUST be the exact Google v4 string enum:
        "ONE" | "TWO" | "THREE" | "FOUR" | "FIVE" (never a raw number!).

--- Endpoint 2: Get Single Review (Used by Revora CRM after Pub/Sub push) ---
GET /api/v4/accounts/:accountId/locations/:locationId/reviews/:reviewId
  Response `200 OK`: Single `GbpReview` object matching schema above (or `404`).

--- Endpoint 3: Create / Update Reply (Mimics `accounts.locations.reviews.updateReply`) ---
PUT /api/v4/accounts/:accountId/locations/:locationId/reviews/:reviewId/reply
  Request Body:
    { "comment": "Thank you for your feedback! We are glad you enjoyed your stay." }
  Validation:
    - Return 400 if `comment` is missing, empty, or exceeds 4096 characters.
    - Return 404 if review not found.
  Behavior:
    - Save `reviewReply: { comment, updateTime: new Date().toISOString() }` onto
      the review in `data/reviews.json` and update `review.updateTime`.
  Response `200 OK`:
    {
      "comment": "Thank you for your feedback! We are glad you enjoyed your stay.",
      "updateTime": "2026-11-25T13:45:00.000Z"
    }

--- Endpoint 4: Delete Reply (Mimics `accounts.locations.reviews.deleteReply`) ---
DELETE /api/v4/accounts/:accountId/locations/:locationId/reviews/:reviewId/reply
  Behavior: Sets `reviewReply: null` in `data/reviews.json`.
  Response `200 OK`: `{}`

--- Endpoint 5: UI Review Submission + Cloud Pub/Sub Push Webhook ---
POST /api/ui/reviews
  (Called by the mock website's "Write a Review" modal; no bearer token needed
   from browser UI, or you may include same-origin request).
  Request Body:
    {
      "locationId": "loc-blr-001",
      "displayName": "Rohan Verma",
      "starRating": "FIVE",
      "comment": "..."
    }
  Behavior:
    1) Generate `reviewId` (e.g., `gbp_rev_${Date.now()}`), timestamps, and save
       to `data/reviews.json`.
    2) Construct the exact Google Cloud Pub/Sub `NEW_REVIEW` push envelope:
       Inner JSON before Base64:
         {
           "type": "NEW_REVIEW",
           "location": "accounts/acc-aurum-01/locations/" + locationId,
           "review": "accounts/acc-aurum-01/locations/" + locationId + "/reviews/" + reviewId
         }
       Outer HTTP POST body to `process.env.CRM_WEBHOOK_URL || "http://localhost:4000/api/webhooks/google"`:
         {
           "message": {
             "data": "<Buffer.from(JSON.stringify(inner)).toString('base64')>",
             "attributes": { "accountId": "acc-aurum-01" },
             "messageId": "msg-" + Date.now()
           },
           "subscription": "projects/revora-sandbox/subscriptions/gbp-reviews-push"
         }
       Headers:
         Content-Type: application/json
         X-Sandbox-Webhook-Secret: process.env.SANDBOX_WEBHOOK_SECRET || "sandbox-gbp-webhook-secret"
    3) Fire the webhook with a 3-second `AbortSignal.timeout(3000)` inside try/catch.
       If `:4000` is offline (standalone teammate dev), catch gracefully and set
       `webhookDelivered: false` — NEVER fail saving the review!
  Response `201 Created`:
    {
      "review": { ...GbpReview },
      "webhookDelivered": true | false
    }
